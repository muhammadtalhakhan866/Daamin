# Daamin Estate & Builder — Website Starter

This starter is a responsive single-page HTML/CSS/JavaScript website based on the available Daamin Estate & Builder company information.

## Files
- `index.html` — complete responsive website starter with embedded CSS and JavaScript.
- `CLAUDE_CODE_BRIEF.md` — instructions to continue building the website in Claude Code.

## Run locally
1. Download and extract this folder.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use Live Server, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Before publishing
- Replace illustrative stock photos with actual, authorized Daamin project images.
- Verify all social profile URLs and contact details.
- Verify the office address, project statuses, exact locations, current availability, and all specifications.
- The contact form currently prepares a WhatsApp message to `+92 321 9281965`. Test this on desktop and mobile.
- Connect a real form backend or CRM if enquiries must be stored.
- Add a proper privacy policy and terms page.
- Confirm the domain and hosting are controlled by the company before deployment.
- Add the official company logo when supplied. The current “D” mark is a temporary text placeholder, not a replacement logo.
- Do not publish unverified claims about approvals, completion, amenities, prices, possession dates, or investment returns.

## Images
Images currently load from Unsplash as illustrative placeholders and require an internet connection. They are not represented as actual photos of the named Daamin projects.
